udemy-clone
A static, responsive Udemy website clone built with pure HTML and CSS. Features sticky navbar, category menu, hero section, course cards, topic explorer, popular courses ranking, promo banner, and a full footer. Built for front-end learning.

🎓 Udemy Clone project
A pixel-perfect, responsive clone of the Udemy e-learning platform built using HTML and CSS — no frameworks, no libraries.

📋 About the Project
This project was built as part of a Week 1 Front-End Development Assignment to practice and demonstrate core HTML and CSS skills by replicating a real-world website — Udemy.

All course cards and layouts are written in plain HTML. All styling, responsiveness, hover effects, and animations are done purely with CSS.

✨ Sections Included
Section	Description
Navbar	Sticky top bar with logo, pill search bar, Log in & Sign up buttons
Menu Bar	Horizontally scrollable category navigation bar
Hero	Gradient banner with sale badge, headline, and CTA buttons
Recommended Courses	8-card responsive grid with ratings, pricing, and badges
Recommended Topics	12 topic chips with emoji icons and a topic suggestion input box
Popular Courses	Numbered ranking list (1–6) with thumbnails and course details
Promo Banner	Full-width purple call-to-action strip
Footer	5-column links, social icons, language button, and copyright
🛠️ Tech Stack
HTML5 — semantic structure, all content written in HTML
CSS3 — Flexbox, Grid, variables, transitions, media queries
Google Fonts — Playfair Display + Noto Sans
SVG — social icons and search icon (inline, no library needed)
📁 Folder Structure
udemy-clone/ ├── index.html ← all HTML structure and content └── style.css ← all CSS styling and responsiveness

📐 CSS Concepts Used
CSS Custom Properties (variables) for consistent colors and fonts
Flexbox — navbar, hero buttons, cards, footer bar
CSS Grid — course grid, topics section, popular courses, footer columns
position: sticky — navbar stays visible while scrolling
position: absolute — Bestseller badges float over thumbnails
linear-gradient — hero background and course thumbnail colors
transition + :hover — smooth hover effects on all cards and links
@media queries — fully responsive layout at 1100px, 860px, and 640px
📱 Responsive Breakpoints
Screen Size	Layout Behavior
Desktop > 1100px	4-column course grid, full navbar with all links
Tablet ≤ 860px	2-column course grid, reduced padding throughout
Mobile ≤ 640px	2-column grid, navbar links hidden, compact layout
